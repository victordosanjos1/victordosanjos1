### 🚀 Projeto em destaque

#### [📄 Sistema de Clientes e Orçamentos — TOP Usinagem](https://github.com/victordosanjos1/Projeto-para-TopUsinagem)

Sistema web interno feito para a **TOP Usinagem – Eletroerosão a Fio**. A equipe cadastra clientes, monta orçamentos, gera o **PDF oficial** e envia por **e-mail**, tudo em um só lugar.

- 🔢 Numeração automática de orçamentos, sem duplicação
- 🧮 Mesmo cálculo na tela, no servidor e no PDF
- 🧊 Documento congelado após finalizado, com revisões
- 📊 Painel com indicadores e filtros
- 🔐 Acesso só por convite e Row Level Security no banco
